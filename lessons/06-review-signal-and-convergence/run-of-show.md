# Run of show: Lesson 6, Review signal and convergence

The single filming sequence: slide range, then demo, then slide range. Slide numbers are 1-based positions in
[deck/index.html](deck/index.html) (33 slides). Every row names the [script.md](script.md) beat it performs, and the
time column is that beat's estimate from the script's running time table. Like lessons 2 to 4, this lesson runs things on
camera: the live beats are real runs, not build-only.

**Pre-filming:** work through [checklist.md](checklist.md), including the dry run on a scratch repo. Run both live
builds once: ask the factory to replace its stub review as in beat 6, then its stub patch as in beat 7, and see what it
plans, what grade scale and threshold it picks, whether the gate refuses a mismatched label and where the no-progress
check lands. Stage the PRs for beat 8 (see the checklist). Re-check the as-of dates in the options file. Nothing for the
demo is pre-queued in `factory/`.
