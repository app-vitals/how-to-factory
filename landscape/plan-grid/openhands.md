# OpenHands: lesson 2 plan grid (spec to plan)

Scope: lesson 2 only, the step where a spec or request becomes a plan. Left out on purpose: test and verification planning
(verification lesson), how specs are written (intake lesson), standards files such as AGENTS.md and skills, estimates and
model tiers, and bundling or PR shaping. Every filled field is a paraphrase of a first-party page, with its URL and the date I
fetched it (**2026-10-19**). Nothing here is carried over from the 2026-10-13 notes in `lessons/README.md` or
`landscape/field-grid/openhands.md`; every page below was fetched again.

"Approval before work starts" uses exactly one of **Human**, **Human approves** or **Automated**, and only where a page
states it. Where a page does not, the cell says `not documented` and names the index pages checked. Names are OpenHands' own,
not canonical. Several surfaces are used because no single one covers every column; each row names its surface.

Headline finding: OpenHands has no product-level "plan mode" or plan-approval step in its docs. The one built-in planning
construct is an SDK example (a read-only planning agent that writes `PLAN.md`, then a second agent that builds from it).
Everywhere else, planning is something the person asks for in the prompt, or it is replaced by a readiness gate on the issue
(acceptance criteria present, label applied) before an agent starts. The docs also show a command-palette entry called "Plan"
in the CLI, described only as "View agent plan"; no page says what it contains or how it is produced.

Method: fetched the docs index (https://docs.openhands.dev/llms.txt, 2026-10-19), listed every page whose title or description
could touch planning, design before coding, code exploration, plan review or approval, and turning a plan into tasks, then
read those pages. The index has no page titled plan, spec, design or roadmap for the product; the only planning hits were the
SDK custom-agent guide and the Jira page. The pages are under "Pages read"; the rest are under "Ruled out (why)".
