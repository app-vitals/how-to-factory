# Contributing

Thanks for your interest in how-to-factory.

## Issues

Issues are welcome: factual corrections, broken links, unclear explanations, and ideas for lessons. For a correction
about another product, please include a first-party source URL and the date you checked it.

## Pull requests

Pull requests are by invitation for now. Please open an issue first and wait for a maintainer to ask for a PR, so
no one spends time on a change we cannot take yet. This may open up later.

If you have been invited:

- Use a Conventional Commit PR title (`feat`, `fix`, `perf`, `revert`, `docs`, `refactor`, `test`, `build`, `ci`, `chore`).
- Run `bun install`, then `bun run typecheck` and `bun test` before pushing.
- Follow the rules in [CLAUDE.md](CLAUDE.md): cite sources for claims about other products, keep lessons tool-neutral,
  and keep decks within the deck rules.

## Security

Do not report vulnerabilities in a public issue. See [SECURITY.md](SECURITY.md).
